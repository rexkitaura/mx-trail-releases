# MX TRAIL — Android 試遊版

TF250-Eで4つのオフロードコースを走る、REX WORKSの個人制作ゲームです。

**現在の配布版: 0.2.0-qa.67（2026-10-25）**。開発途中の試遊版です。画質・操作・動作性能は調整中で、正式版ではありません。

- [Android APKをダウンロード（約157MB）](https://github.com/rexkitaura/mx-trail-releases/releases/download/v0.2.0-qa.67/MXTrail-0.2.0-qa.67.apk)
- [リリース情報と確認用ファイル](https://github.com/rexkitaura/mx-trail-releases/releases/tag/v0.2.0-qa.67)

公開APKのダウンロードにGitHubアカウントや支払いは不要です。通信料は利用する回線の契約によります。

## 対応環境

Android 8.0以上・64bit ARM（arm64-v8a）。実機確認はLenovo Legion Tab 8.8 Gen 3で行っています。その他の端末の動作は未確認です。iOS、32bit Android、PCにはこのAPKをインストールできません。

## 遊べる内容

- SUGO / OFV / KODAMA / KEGONの4コース、レースとフリー走行。
- 操舵・アクセル・ブレーキ・前後荷重。変速は6段オートです。
- 回転数と同期するエンジン音、転倒した場所での起き上がり。
- 回転帯・速度・ギア・地図をまとめたRACE STRIP UI。

操作と導入方法は [INSTALL_JA.md](INSTALL_JA.md) を参照してください。

## 現在の制限

- 森林など描画負荷の高い場所ではフレームレートが下がります。全コースでの持続60fpsは未達です。
- グラフィックス、ライダーの動作、タッチ操作は引き続き調整中です。
- 旧Web版・旧WebView APK 0.1.1とは別アプリです。旧版のセーブデータの引き継ぎには対応していません。
